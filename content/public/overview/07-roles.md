  - title: Читает чертёж
    name: Чтение
    stage: Исходный лист
    kind: llm
    icon: tolerances
    when: После загрузки чертежа и выбора условий запуска.
    input: Изображение листа и задача на чтение детали.
    output: Сведения о детали, размерах, материале и технических требованиях.
    limits: Не заменяет проверку спорных обозначений и не подтверждает производственную пригодность.
  - title: Сопоставляет результат с листом
    name: Перепроверка
    stage: Паспорт
    kind: llm
    icon: coverage
    when: Если перед запуском включена перепроверка.
    input: Исходный чертёж и результат первого чтения.
    output: Замечания, допустимые исправления и оставшиеся вопросы.
    limits: Не делает неразборчивое место достоверным без достаточного основания.
  - title: Исследует конкретный вопрос
    name: Уточнения
    stage: Недостающие сведения
    kind: llm
    icon: search
    when: Когда выбран поиск ответа на открытый вопрос.
    input: Сам вопрос, сведения о детали и доступный источник.
    output: Ответ с основанием, допущением или обозначенным ограничением.
    limits: Неразрешённый вопрос должен остаться видимым.
  - title: Предлагает последовательность операций
    name: Планирование
    stage: Предварительный маршрут
    kind: llm
    icon: scenarios
    when: После подготовки исходных сведений для планирования.
    input: Паспорт, заготовка, количество и принятые условия.
    output: Предварительная карта обработки с ограничениями.
    limits: Карта требует технологической оценки и ещё не является окончательным маршрутом.
  - title: Прорабатывает содержание операций
    name: Детализация
    stage: Состав работ
    kind: llm
    icon: machines
    when: При переходе к подробной проработке выбранного маршрута.
    input: Сведения о детали, маршрут, оборудование и решения по вопросам.
    output: Работы, установки, цели обработки и исходные условия для расчёта.
    limits: Отсутствующее условие нельзя подменять вымышленным режимом или нормой.
  - title: Проверяет и считает
    name: Программа
    stage: Все этапы
    kind: code
    icon: metrics
    when: При обработке и пересмотре связанных данных.
    input: Принятые факты, условия, справочные значения и состав работ.
    output: Проверенные численные результаты и сохранённое состояние работы.
    limits: Правильная арифметика не доказывает пригодность исходных условий для производства.
