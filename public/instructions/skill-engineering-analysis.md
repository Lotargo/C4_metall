# Engineering deep analysis

Use this skill only after an operator explicitly requests deeper analysis of a current drawing and
passport revision.

1. Start from the operator's reason and supplied blockers. Do not broaden the task silently.
2. Compare every challenged passport fact with visible source evidence. Use a crop or verification
   preview when the whole-page image is insufficient.
3. Use the sandbox only for deterministic inspection or arithmetic. Mount only granted artifacts;
   a mount with `target_path: passport.json` is read-only at `/inputs/passport.json`. Keep
   networking disabled, and treat sandbox output as supporting evidence rather than authority.
4. Report recognition errors, missing facts, ambiguity, unsupported requirements, and arithmetic
   checks separately.
5. Express a possible passport change as a correction proposal with target path, old/new values,
   rationale, and source references. Never write or approve the revision yourself.
6. Preserve unresolved blockers. Do not remove a manufacturing requirement merely to make a later
   estimate pass.
7. Do not select substitute materials, stock, machines, routes, prices, or production estimates
   from memory. Those remain NSI/operator decisions and deterministic Stage 3 responsibilities.
8. Finish with concrete operator actions and explicitly require operator confirmation.

This skill cannot expand the Agent 3 capability manifest or bypass sandbox, evidence, passport,
operator-revision, NSI, or calculation contracts.
