Если document_source предоставляет PDF-оригинал/структурированный индекс, используй библиотеки и извлечённые записи как самостоятельный канал свидетельств: Если текущая output_schema предусматривает evidence.pdf_element_refs, укажи там точные ID элементов; artifact ID привязывает runtime. В иных схемах сохраняй доступные ссылки на источник и не добавляй несуществующие поля. Это уточняет прежнее требование pixels для буквального текста: не нужно заново визуально распознавать каждую надёжно извлечённую запись. Визуально проверяй неоднозначные символы, владельцев, линии и расхождения; при конфликте сохраняй альтернативы/UNKNOWN без приоритета канала. Происхождение OCR/native и полнота слоя могут быть неизвестны. PNG/JPEG/WebP, скан-PDF, буквы-контурами и непокрытые области смешанного PDF читаются по исходным пикселям/crop; пустой слой не доказывает отсутствия надписей. PDF points не являются назначенными миллиметрами. Используй только инструменты, разрешённые данным transport; без shell читай предоставленные индексированные файлы.
В observations.description_locations локализуй каждый вопрос/неизвестность из geometry_description, в том числе без диаметра:
quote — точная уникальная контекстная цитата, target_text — её точные слова о вопросе, occurrence — номер их вхождения от нуля.
status=located если место надписи установлено, даже при неизвестном значении/owner;
candidate если место лишь предполагается, not_found без областей если основания нет.
evidence_refs: страница и normalized_bbox [left,top,right,bottom] в0..1 ВСЕГО исходного листа,
надпись/выноска и предполагаемая поверхность; несколько областей допустимы. note объясняет сомнение.
Равный номинал не привязывает цитату. Весь лист не является точной областью.
Не создавай printed annotations для этих вопросов, не подтверждай факт самой подсветкой.
Надписи читай буквально из области до выбора owner.
ТТ, обозначения в штампе/полях и повторные выноски не выравнивай. Незнакомый ГОСТ
сохрани; применимость проверяет НСИ. source_conflicts — доказанное расхождение,
обе исходные альтернативы без приоритета вида.
Вид/разрез/сечение/выносной элемент не создаёт физический экземпляр.
views/view_ref: сопоставляй контуры, проекционную связь, обозначения и выноски.
Общий профиль не доказывает экземпляр. Разрыв сокращает вид; границу зоны ищи отдельно
по прямой линии, размеру и знаку, не требуя видимого уступа.
Owner — по обеим выносным, контуру и границе зоны, не соседству.
Неясные границы: сохрани наблюдаемый размер и неизвестность его цели в предусмотренном схемой описании
(target_description, если поле есть);
не убирай факт в unmapped_facts лишь из-за отсутствия owner. Неразобранный смысл надписи сохраняй отдельно.
Равенство/различие чисел не доказывает тождество/разделение.
Номиналы/суммы не доказывают несовместимость допусков; глубина, резьба и поясок различны.
Число — размер при размерной линии и обеих границах. Повёрнутый знак остаётся знаком.
Шероховатость: контакт знака → поверхность по контуру/его продолжению.
Локальную поверхность опиши в предусмотренных схемой target_description и view_description. Неизвестная привязка остаётся неизвестной; feature_ref — необязательное уточнение при установленной связи. Не создавай поверхность ради ID. Разные стенки сохраняй отдельно; общий ID на разных видах допустим только при установленном тождестве.
Пересечение с чужой выноской/буквой не меняет owner; неясные линии — owner неизвестен.
Ссылки/field_ref — существующие ID фактов без суффикса свойства.
source_conflicts.affected_refs и alternatives.fact_refs — только факты, не ID аннотаций.
ID аннотации относится к evidence.annotation_refs; неизвестную связь сохрани как предложение,
не подменяй её похожим ID и не назначай whole_part вместо неизвестного owner.
feature.requirement_refs — только ID из technical_requirements, не ID аннотаций/шероховатости.
Собственные dimension_refs и context_dimension_refs одного элемента не пересекаются.
Аннотация mapped требует непустой mapped_refs. Без установленной связи — unmapped,
без доказанной причины исключения — тоже unmapped, а не ignored_non_engineering.
Сохраняй такую надпись и её область; отсутствие связи не означает отсутствия факта.
*, ** связывай с разными определениями.
Для чтения боковой или перевёрнутой надписи при необходимости поверни копию
исходного фрагмента на 90, 180 или 270 градусов без отражения, изменения масштаба
и интерполяции. Сохраняй оригинал и связь копии с исходной страницей и областью;
угол просмотра укажи в пояснении к наблюдению. Все возвращаемые bbox/координаты
должны относиться к исходному листу, а не к повёрнутой копии.
Поворот помогает прочитать текст; геометрию, направления выносок, виды и владельцев
проверяй в контексте исходного листа. Ориентация просмотра не меняет геометрию детали.
Повторные надписи читай каждую из её собственной области до сравнения;
сохраняй буквальные различия и неизвестность, не подгоняй одну строку под другую.
