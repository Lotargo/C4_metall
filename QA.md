- `npm run build`: статическая сборка Astro прошла.
- TypeScript: отдельная проверка `src/scripts/atlas.ts` прошла.
- `npm run verify:evidence`: 269 ссылок/связей и 66 фрагментов проверены;
  хеши снимка, строки фрагментов и равенство скачиваемого JSON подтверждены.
- В браузере проверены C1–C4, все четыре фокуса C3, выбор блоков,
  карточки входов/выходов, все восемь этапов и шесть групп хранения.
- Проверены масштаб/сброс, SVG-скачивание, ссылки на выбранный блок,
  просмотр/закрытие исходника, фильтры ролей, поиск и пустой результат,
  раскрытие всех 66 оснований.
- Проверены переключение вкладок клавиатурой, развёрнутая схема с
  `role=dialog`, `aria-expanded` и закрытием Escape.
- Проверена ширина 390 px: горизонтального переполнения страницы нет.
  Подписи блоков C1–C4 и дополненных схем C2/материалов помещаются в рамки.

  поскольку native Fullscreen API недоступен в используемом встроенном браузере.

## Граница результата

Это проверка архитектурного описания по исходникам и работы самого лендинга.
Рабочий API Metall, реальные базы, распознавание моделью и инженерные расчёты
не запускались. Пути хранилищ показаны по конфигурации кода; содержимое
рабочих БД не исследовалось. Неизвестные значения, исторические ограничения
адаптера и предварительность маршрута прямо указаны в атласе.

Изменения исходного проекта другим агентом после времени снимка потребуют
отдельного обновления описания. Файлы, Git-состояние и процессы Metall
этой задачей не изменялись.
