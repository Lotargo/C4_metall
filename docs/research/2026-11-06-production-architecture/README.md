## Основание

Исходный продукт: `F:/projects/metall-dev-2`. Ветка `test-2`, HEAD `d9329696188fb1ad9d103ac3ad55908e55d37856`. В снимок включены незакоммиченные изменения рабочего дерева, в том числе новый `compact-detail-intent/1`. HEAD сам по себе не воспроизводит этот снимок. Точное основание каждого файла фиксирует SHA-256 в реестре.

Новый вход из UI использует `pipeline_mode=compact_round`. В этой ветви чтение, перепроверка и предварительная карта выполняются до подтверждения оператором; DETAIL запускается после подтверждения сохранённых входов и карты. Прежнюю схему D001 с отдельными G1/G2 нельзя автоматически переносить на эту ветвь.

В проекте есть три выделенных Go-сервиса: материалы, подбор заготовки и расчёты обработки. Оркестрация, агенты, локальная развёртка проходов, нормы времени и итоговая смета остаются в Python backend Metall.

Новый DETAIL сохраняет результаты операций. Стоимость в текущем UI собирается отдельной командой оператора `cost-estimate`; `machine-estimate` сначала пересчитывает сохранённые технические входы по карточкам, затем стоимость. Автоматический оценочный прогноз не запускается после каждого нового DETAIL. Точные условия и ссылки приведены в документах 01, 06 и 07.

## Как читать формулы

- **Основной путь**: вычисление прослежено из `compact_round` и вызываемых им модулей.
- **Доступный метод ядра**: реализован в `machining-calc`; вызов требует подходящего задания, а наличие метода не означает обязательный вызов на каждом чертеже.
- **Оценочная ветвь**: расчёт выполняется по явно выбранным профилям и допущениям. Численный ответ не превращает их в подтверждённую производственную норму.
- **Дополнительная/прежняя ветвь**: код есть в продукте, но его нельзя выдавать за штатный путь новой загрузки `compact_round`.
- **UNKNOWN**: нужный факт, режим, норма или часть работ отсутствует. Известная часть сохраняется, неизвестная не заменяется нулём.

«Все формулы» в комплекте означает предметные вычисления подготовки производства и связанные с ними преобразования: размеры, допуски, заготовка, раскладка, геометрия, проходы, режимы, время, нагрузки, энергия, стоимость и оценочные диапазоны. Отдельно показаны прежние ветви. Реестр исходников дополняет изложение буквальными выражениями, чтобы редакционное объединение одинаковых зависимостей не скрывало варианты реализации.

Хеширование, идентификаторы, сортировка строк, счётчики ревизий, верстка, сетевые задержки и тестовые эталоны не являются дополнительными инженерными формулами. Арифметический поиск может захватывать такие выражения; их наличие в проверочном реестре не объявляет их расчётной методикой.

Он не подтверждает новый запуск моделей, качество чтения какого-либо рабочего чертежа, применимость режимов к реальному станку или получение полной производственно принятой сметы. Текущие значения рабочих БД и содержимое `mvp/.env` не исследовались. Сохранённые на диске профили, нормы и коммерческие значения могут отличаться от исходных заводских наборов.

Материалы находятся вне каталога публикуемых документов. Исходный продукт, сайт и существующий архитектурный атлас этим комплектом не изменяются.
