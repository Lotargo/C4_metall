Дата: 2026-10-27.

Проба впоследствии удалена. Текущий общий редактор и его проверки:
[Firebase](2026-10-27-editor-firebase.md).

Эта запись описывает первую пробу. Последующее уточнение интерфейса, отказ от
архива версий и история 20 действий: [актуальная проверка](2026-10-27-editor-history.md).

## Объём

Отдельная локальная страница `/editor-preview/` на Tiptap 3.32.0. Исходный
`documents/implementation/16-ПЛАН_ИНЖЕНЕРНЫХ_РАСЧЁТОВ_2026-10-27.md`
не изменялся. metall-dev-2 не изменялся и не запускался.

Нажатие на текст сразу позволяет ввод. ПКМ открывает меню оформления без
переключения режима: полужирный, курсив, подчёркивание, зачёркивание, заголовок,
подзаголовок, обычный абзац, цвет текста и выделения, очистка оформления.
Кнопка «Форматирование» и Shift+F10 дают альтернативный доступ к меню.

Markdown импортируется через AST Remark до преобразований просмотра. Для
таблиц используются штатные узлы Tiptap; для LaTeX, Mermaid и служебного HTML
сделаны отдельные узлы. Неизвестный синтаксис отклоняется с ошибкой импорта.
Содержимое сохраняется в JSON; преобразования сохранённой копии обратно в
Markdown в этой пробе нет.

## Хранение

- Локальный dev API: `GET/PUT /api/editor-prototype/document`.
- Текущая копия: `.local/editor-prototype/current.json`.
- История: `.local/editor-prototype/revisions/`.
- Снимок содержит оригинальный Markdown и его SHA-256, документ, номер версии
  и время сохранения. Перед заменой текущего файла записывается отдельная версия;
  текущий файл заменяется переименованием временного файла.
- Проверка базовой версии возвращает 409 при устаревшей записи. Очередь записи
  защищает два одновременных запроса в одном экземпляре dev-сервера.
- Аварийная копия неподтверждённых правок хранится в localStorage с номером
  базовой версии и хешем исходника. Это дополнение к серверному сохранению.
- Успешный статус появляется после ответа API. При конфликте доступно скачивание
  своей JSON-копии и явное открытие серверной версии.
- API существует только в dev-сервере, привязанном к 127.0.0.1. В статической
  сборке пробная страница перенаправляет к `/implementation/`; содержимого копии
  в этой странице нет. Общий интернет-сервис и авторизация ещё не подключены.

## Проверки

`npm run test:editor`: 4/4 проходят. Проверены:

1. Состав импорта сопоставлен с независимым обходом AST настоящего плана.
2. Транзакция ProseMirror вставляет кириллицу с двумя пробелами, применяет пять
   видов оформления; после записи на диск, создания нового хранилища и
   восстановления документа сравнивается полное содержимое защищаемых узлов.
3. Две записи одной базовой версии не могут обе завершиться успешно;
   некорректный документ не замещает текущий.
4. Неподдерживаемый Markdown и некорректная структура явно отклоняются.

Проверка в Chrome:

- Ввод по клику и выделение клавиатурой.
- Настоящее ПКМ-меню; полужирный, курсив, подчёркивание, цвет и выделение.
- Абзац последовательно превращён в H2, H3 и обратно в P; оглавление обновляется.
- Исправлен обнаруженный случай: ПКМ без выделения теперь перемещает позицию
  команды к указателю, вместо применения к прежнему абзацу.
- Сохранение и перезагрузка сохраняют введённые двойные пробелы и оформление.
- В пустую ячейку таблицы введено «Проверено», сохранено и повторно открыто;
  эта же версия прочитана во втором, независимом in-app браузере.
- Тестовый текст ячейки затем удалён и сохранён. Оформленный фрагмент
  «Проверка  редактора.» оставлен в пробной копии как демонстрация.
- Проверен Ctrl+клик по внутренней ссылке `#add-d05` и переход по оглавлению.
- Светлая/тёмная темы отображают документ; Mermaid перерисовывается при смене.
- На ширине 390 px нет горизонтального переполнения страницы; меню помещается
  в экран. Альтернативная кнопка форматирования, стрелки и Escape работают.

Итоговая сохранённая версия при проверке: 21. Сопоставление полного содержимого
защищаемых узлов с исходным импортом проходит. Отчёт и снимок экрана:
`outputs/editor-prototype-2026-10-27/preservation.json`, `context-menu.png`.

Также проходят `npm run typecheck`, `npm run verify:evidence`, обычная сборка
и сборка с `/C4_metall/` в отдельный `outputs/.../github-dist`. Проверено, что
обе статические страницы пробы содержат перенаправление, а не копию документа.

## Границы

Формулы и Mermaid сейчас отображаются как защищённые визуальные узлы; изменение
их внутреннего языка не входит в пробу. Нет Markdown-экспорта, интерфейса истории,
одновременного редактирования с курсорами участников или production-хранилища.
Произвольные изображения и другие неиспользуемые в настоящем плане конструкции
не покрыты импортом. Сетевые отказы и восстановление после аварии процесса
не симулировались в браузере.

Сборка сохраняет предупреждение о крупных chunks. `npm audit` сообщает о
предшествующей этой работе зависимости `undici@8.11.2` в Astro → unifont;
та же версия присутствует в HEAD до добавления Tiptap. Автоматическое обновление
несвязанных зависимостей не выполнялось.

Коммит, push и публикация не выполнялись.
