## Что изменилось в описании

Каждое утверждение проверено по фрагменту нового снимка; ссылки доступны на `/it/`.

- **Чтение.** Общие правила (`SOURCE_READING_SCOPE_PROMPT`) добавляются ко всем
  ролям: буквальная надпись, затем владелец по выносным линиям и границе зоны;
  вид не создаёт физический элемент. В `autonomous` сторона, роль и цитата
  задаются описанием полей `AutonomousFeatureItem`; в concise, reading_v2 и
  minimal — также текстом инструкции. Для `codex_cli`, `opencode_cli` и
  `antigravity_cli` первичное чтение получает полный рендер в
  `recognition_workspace`; счётчик crops нативные увеличения не учитывает.
- **Паспорт.** `Feature`: `physical_side`, `geometry_role`, `requirement_refs`,
  `classification_evidence`, виды `cylinder` и `plane`. `DrawingPassport`:
  `geometry_description`, `geometry_mentions`. Упоминание — не факт чертежа;
  роль переносится только по уникальной цитате ровно одного элемента.
- **Сборка.** Ссылки приводятся к существующим ID; расхождения модели и
  детектора объединяются по источникам. Новая детерминированная роль
  «Сверка описания» — всего десять ролей, из них три обычным кодом.
- **Таблица.** Диаметр по умолчанию «сторона не установлена»; подпись по стороне
  и роли владельца; отдельные подписи размеров заготовки и расположения.
- **Подбор.** `physical_geometry` исключает размеры stock/position; приоритет
  явной общей длины с подтверждённым верхним пределом; конфликт с осевой цепью —
  только при непересекающихся диапазонах. Подбор и маршрут используют один
  закреплённый снимок НСИ; без проверяемой версии формул — `UNKNOWN`.
- **Маршрут.** Количество по умолчанию 1 шт.; габарит и плановая масса на каждом
  состоянии; ссылки операций на любые адресуемые элементы паспорта; локальные
  условия остаются в операции; условием маршрута становится только проваленная
  проверка. Методика требует сохранять оба разночтения.
- **Интерфейс.** Реестр «Поверхности и принадлежность размеров»: сторона, роль,
  размеры, требования, ответы на упоминания; основание обязательно, отметка
  «Сверено с оригиналом» меняет статус свидетельства. Ревизия открывается новым
  запуском; обзор распознавания показывает текущую ревизию паспорта.
- **C4.** Новый блок `GeometryMention[]` на уровне кода; обновлены описания
  узлов, связи «Физическая геометрия» и «Наблюдения + описание».
