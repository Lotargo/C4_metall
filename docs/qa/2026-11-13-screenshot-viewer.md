# Оформление скриншотов и начальный масштаб

Дата: 2026-11-13. Статус: выполнено, локально проверено.

Снимки на страницах результатов выделены общей рамкой, цветной шапкой
«Скриншот интерфейса», внутренними отступами и действием «Открыть целиком».
Под превью указано, что показан фрагмент. Оформление применяется ко всем
паспортам, маршрутам и сметам через общий компонент ResultBody.

Вертикальные снимки открываются по ширине с прокруткой. Прежний порог 2:1
не включал этот режим для смет с пропорцией около 1,9:1. Новый критерий —
высота больше ширины. До загрузки изображения используются его исходные
размеры из HTML; после загрузки — фактические размеры. Ручной выбор масштаба
сохраняется после загрузки, повторное открытие возвращает начальный режим.
Заголовок просмотрщика соответствует разделу: паспорт, маршрут или смета.

Проверены:

- `npm run typecheck`, `npm run verify:evidence`, `npm run build` — успешно;
  сборка содержит 15 страниц, проверено 716 ссылок.
- `npm run test:editor` — 16 тестов успешно.
- Браузер: 24 сочетания страницы, ширины и темы; 1440, 390 и 320 px,
  светлая и тёмная темы, переполнения страницы нет.
- 18 открытий просмотрщика: начальный режим по ширине для всех девяти
  снимков, переключение трёх масштабов, прокрутка до конца, клавиатура,
  Esc и возврат фокуса.
- Задержанная загрузка: режим по ширине установлен до получения изображения;
  ручное «Вписать» сохраняется после загрузки; повторное открытие — по ширине.
- Все девять JPEG совпадают с ранее проверенными файлами по SHA-256;
  сами изображения и инженерные данные не изменялись.

Протокол и контрольные кадры: `.evidence/screenshot-frame-2026-11-13/`.
Ошибок страницы и внешних запросов нет. Сервер проверки закрыт.
