# План реализации: документы Markdown

Дата проверки: 27 октября 2026.

## Изменения

- Отдельный раздел `/implementation/`, ссылки с главной и страниц результатов.
- Слева список документов и оглавление `##`/`###`, справа текст документа.
  Оформление использует палитру, шрифт и пропорции раздела результатов.
- Коллекция Astro автоматически подключает `documents/implementation/**/*.md`.
  Метаданные `title`, `description`, `order` необязательны. Заголовок меню
  берётся из `title`, первого `#` или имени файла. Сортировка: `order`, затем путь.
- Каждый документ получает собственный адрес. Относительные ссылки на `.md`
  преобразуются в ссылки на страницы с сохранением фрагмента и базового пути.
- Markdown с таблицами GFM, списками с отметками и подсветкой кода.
- Mermaid строит SVG в браузере, загружается по требованию только на документах
  со схемами. Режим `strict`; исходный текст доступен даже при ошибке схемы.
- LaTeX `$...$` и `$$...$$` обрабатывает KaTeX при сборке: HTML + MathML.
  `trust: false`; одна версия KaTeX для рендеринга и локального CSS/шрифтов.
- На узком экране навигация раскрывается над документом. Выбор раздела закрывает
  меню и переводит фокус на заголовок. Есть печатные стили и кнопка печати.

Инструкция по добавлению: [documents/README.md](../../documents/README.md).
В публичном разделе показываются только готовые добавленные документы.
Вводная страница, пример и пояснения о форматах удалены по уточнению задачи.
Структура и метаданные документа не обязательны; инструкции для добавления
остаются только в репозитории. При отсутствии документов отображается
«Документы пока не добавлены».

## Границы

Сайт статический: новый документ доступен в опубликованной версии после сборки
и публикации. В dev-режиме файлы подхватывает Astro. КаTeX поддерживает свой
математический синтаксис, а не произвольный TeX-проект. Без JavaScript остаются
доступными Markdown, формулы, ссылки и текст схем.

Сборщик предупреждает о размере одного из загружаемых модулей Mermaid (>500 kB).
Модуль не загружается на главной, в результатах и документах без диаграмм.
`npm audit` сообщает об одной прежней high-уязвимости транзитивного `undici`
8.11.2; эта версия присутствовала в исходном lockfile. Новые предупреждения
KaTeX устранены согласованием версии через `overrides`.

Архитектурный снимок не обновлялся. Исходный продукт, его БД, API, модели
и процессы не изменялись и не запускались. Коммит, push и публикация не выполнялись.
