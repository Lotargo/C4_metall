# Общий редактор Firebase — 27 октября 2026

## Поведение

Каждый посетитель редактирует обычные страницы `/implementation/` без окна
входа, регистрации, выбора аккаунта и отдельной кнопки редактирования.
Firebase Anonymous Auth создаёт сессию автоматически. Google-вход и список
разрешённых редакторов не используются. Публичная конфигурация веб-приложения
находится в `src/data/firebase.json`; административных ключей в проекте нет.

Полный JSON Tiptap хранится строкой `contentJson` в
`implementationDocuments/<sha256(documentId)>`. Поля `etag`, `sourceSha256`,
`updatedAt`, `updatedBy` обеспечивают проверку актуальности и метаданные записи.
История версий не создаётся. Запись выполняется после паузы в наборе, с
подтверждением Firestore; статус «Сохранено» появляется после успешной записи.
Подписка `onSnapshot` доставляет сохранённые правки другим открытым окнам.

Правила `firestore.rules` разрешают каждому посетителю с автоматически
созданной сессией создание и обновление документов указанного формата.
Проверяются состав полей, размер содержимого, автор сессии и серверная дата.
Удаление, перечисление документов и доступ к остальным коллекциям закрыты.
Обновление не позволяет изменить `documentId` и `sourceSha256` записи.
Правила опубликованы в проекте `metall-da3a3`, провайдер Anonymous включён.
Исключение индекса для `contentJson` задано в `firestore.indexes.json`.

## Границы

Автоматического посимвольного слияния одновременных правок нет. При конфликте
редактор сохраняет собственный черновик и предлагает скачать его перед
открытием общего документа. Чужая сохранённая запись загружается с новой
локальной историей, чтобы Ctrl+Z не отменял правки другого посетителя.

Исходные `.md`, прежние локальные сохранения и архитектурный снимок сохранены.
Firebase не переписывает `.md`; обновление исходника после облачных правок
требует сознательного согласования. Перенос прежнего локального черновика в
облако автоматически не выполняется.

Использованы официальные SDK Firebase 13.1.0. Типы необязательных методов
Temporal подключены через `temporal-spec/global` без полифила в браузере.
Транзитивный `@grpc/grpc-js` закреплён на 1.14.6; после установки осталась одна
ранее существовавшая проблема `npm audit` в `undici` из дерева Astro.

Сам сайт пока не опубликован заново; настройка Firebase и правила применены.
