# Редизайн по Metall-formulas

Дата: 2026-11-13. Статус: локальная реализация и проверка завершены.
Публикация, push и изменение размещённой версии не выполнялись.

## Цель и основание

Перенести визуальную систему `F:/projects/Metall-formulas` в C4_metall:
типографику, палитру, иконки, композицию, баннер и футер. После уточнений
по трём приложенным примерам дополнительно оформить заголовки блоками,
переработать перечисления и роли, добавить содержательные взаимодействия
и короткие анимационные эффекты.

Референс использован только для чтения. Его исходный HEAD при начале работы:
`1e2f042`; рабочее дерево уже содержало незакоммиченные изменения.
Использованы рабочие `handbook.css`, `chrome.py`, `editorial.py`, `icons.json`
и `sidebar-art.svg`. Локальные хеши записаны в
`outputs/redesign-2026-11-13/reference-hashes.json`.

В C4_metall также уже были незакоммиченные изменения, включая раздел
документации. Их исходный вариант сохранён в локальной папке
`outputs/redesign-2026-11-13/baseline/`; существующие тексты и маршруты
включены в новый общий интерфейс.

## Реализация

| Требование | Результат |
| --- | --- |
| Типографика | Локальный Inter Variable, кириллица и латиница, основной текст 16 px, единая иерархия презентации, документов, таблиц, Mermaid и C4 |
| Палитра | Холодные серые поверхности, синий акцент, тёмная навигация; две темы |
| Иконки | SVG Lucide из референса, общий компонент Icon; лицензии сохранены |
| Баннер | Тёмная поверхность, инженерная SVG-иллюстрация и четыре подписанных этапа без вымышленных показателей |
| Футер | Общий брендовый блок и навигация на всех 15 собранных маршрутах |
| Заголовки | Двухчастные панели с иконкой и пояснением; оформленные заголовки документов |
| Перечисления | Карточки принципов, этапов, анатомии инструкций и хранения; сохранён исходный текст |
| Роли | Карточки с нативным раскрытием, поиск, фильтры, счётчик и состояние пустого поиска |
| Схемы | Выбор участника и блока, подсветка связей, переходы к соседям, представления «Схема» и «Шаги» |
| Телефон | Модальная навигация, одна колонка карточек, панель связей непосредственно в выбранном шаге |
| Анимации | Короткие появления и отклики на transform/opacity; отключение при reduced motion |

Исправлен воспроизводимый дефект счётчика: прежний общий селектор
учитывал 13 ролей и 10 блоков инструкций как 23 роли. Фильтрация теперь
затрагивает только строки с `data-agent-kind`; поиск использует название,
задачу и этап роли. Инструкции остаются видимыми независимо от фильтра.

Основные файлы: `SiteHeader.astro`, `SiteFooter.astro`, `SectionHeading.astro`,
`Icon.astro`, `Blueprint.astro`, `Flow.astro`; `metall.css`, `interactive.css`;
`site-shell.ts`, `flow-interactions.ts`, `ui-effects.ts`, `shared.ts`.

## Проверка

- `npm run verify:evidence`: успешно, 475 ссылок/связей и 130 фрагментов.
- `npm run typecheck`: успешно.
- `npm run test:editor`: 16 из 16 успешно; в том числе сохранность исходных
  требований, формул, статусов и отдельно маркированных дополнений.
- `npm run build`: успешно, 15 маршрутов; 28 хешей исходников вложений проверены.
- Сборка с `/C4_metall/`: успешно; локальные HTML-ссылки на маршруты и ресурсы
  проверены относительно этого префикса. Результат:
  `outputs/redesign-2026-11-13/asset-validation.json`.
- Сверка 22 защищённых файлов документов, данных и реестров снимков:
  изменений относительно начала редизайна нет. Исходные хеши:
  `outputs/redesign-2026-11-13/content-hashes.json`.

В браузере проверены широкие экраны 1280/1440 px, планшет 768 px,
телефон 390 px и узкий экран 320 px. Представительные маршруты:
`/`, `/documentation/`, `/implementation/`, `/results/`, `/plan/`, `/voksa/`, `/it/`.
Проверены обе темы, загрузка Inter, отсутствие горизонтального переполнения
страницы, меню и возврат фокуса после Escape, вкладки этапов, просмотр снимков,
режим показа и выделение активного раздела, переключение C4.

Для новых взаимодействий проверены:

- выбор планировщика в схеме, переход к проверке и затем к отрезке;
- фильтрация участников, переключение между схемой и шагами;
- выбор SVG-блока Enter, переход стрелкой, снятие выбора с возвратом фокуса;
- счётчики 13/9/4, поиск «токар», нулевой результат и очистка;
- сохранность видимости инструкций при фильтрации ролей;
- раскрытие панели внутри LI выбранного шага на телефоне;
- эмуляция reduced motion: переходы карточек `0s`, полоса чтения отключена;
  после проверки эмуляция снята;
- отсутствие ошибок в консоли на итоговых проверенных страницах.
