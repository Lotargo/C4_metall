# Время, расход и стоимость

**09.11.2026. Частично.** Сохранённые исходные значения и результаты проверены на отдельных расчётных участках. Примеры показывают измеримые части расчёта. Полных производственных итогов по контрольным деталям пока нет.

## Рез круглого прутка

Для прямого поперечного реза сплошного круга площадь сечения в см² равна `A = πD² / (4 × 100)`, где `D` — диаметр круга в мм. Время реза `t = A / Q` в минутах, где `Q` — применимая площадная производительность пилы в см²/мин. Загрузка, подача и зажим имеют отдельные основания. Длительность реза сама по себе покрывает движение полотна в материале.

- Штуцер И653-01.01.01.01.02, условный круг Ø28. Площадь 6,157522 см² при 8 см²/мин даёт 0,769690 мин. С отдельной оценкой вспомогательной работы 0,6 мин известный подытог 1,369690 мин/деталь. Точение и контроль открыты.
- Вал В.1883.25.000.000, назначенный Ø30. Площадь 7,068583 см² при 3 см²/мин даёт 2,356194 мин. Пригодность круга и архивного режима пилы UNKNOWN.

Для отдельного линейного рабочего движения `t = L / v`, где `L` — суммарный путь в мм, `v` — рабочая подача в мм/мин. У контрольной втулки ОЗЭМ.121.006.04.000.002 три фрезерных хода по 135,8 мм при условных 100 мм/мин дают 4,074 мин. Подвод, возврат и наладка требуют отдельных оснований. Полный цикл учитывает включённые движения один раз.

## Расход длины и масса

В контрольной раскладке для втулки Ø52 × 6000 мм на номинальный отрезок 108 мм расходуется дополнительно 2 мм пропила. Расход `108 + 2 = 110 мм`. При одном отрезке расчётный остаток `6000 − 110 = 5890 мм`, а вместимость `⌊6000 / 110⌋ = 54` отрезка. Проверка использует нулевые бюджеты торцевой обрезки и зажимного остатка. Фактические потери и деловой остаток определяют по условиям цеха.

Масса цилиндра `m = ρπD²L/4`, где `D` и `L` заданы в м, `ρ` в кг/м³. Для диаметра 0,052 м, длины 0,108 м и плотности 7859 кг/м³ масса отрезка 1,802551 кг. Это геометрический расчёт. Начисляемое количество партии подтверждается отдельно.

## Начисления

Для работ с почасовой ставкой `C = (T / 60) × R`, где `T` — минуты на партию, `R` — ставка в ₽/ч. Для штучной нормы минуты умножают на количество изделий. Разовую загрузку прутка включают по числу таких событий.

У контрольной втулки при одной детали пять известных строк включают 2,123717 мин реза, 0,6 мин вспомогательной работы, 4 мин одной загрузки прутка, 4,193618 мин токарных ходов и 4,074 мин фрезерных ходов. При 1 000 ₽/ч сумма известных работ 249,86 ₽. Коэффициент обработки 1,20 даёт 299,83 ₽ с надбавкой 49,97 ₽. Суммы округляются до копеек после расчёта по исходным значениям.

Материал начисляется отдельно по формуле `Cмат = q × p`. В проверке условная цена 120 ₽/кг и отдельно заданные 0,1413 кг к оплате дают 16,96 ₽. Коэффициент наценки применяется к обработке. Материал входит в отдельную статью сметы. Полный итог требует оценки всех обязательных работ, материала и применимых условий.
