# Два документа в категории «Планы»

Дата: 06.11.2026.

## Изменение

В `/implementation/` публикуются только «Общий план» и «Инженерные расчёты».
В боковой навигации оба документа находятся в одной раскрываемой категории
«Планы». Их адреса, идентификаторы редактора и исходные тексты сохранены.
Общий план по-прежнему открывается первым.

Документы `operator-review.md`, `workspace-uiux.md` и
`customer-progress-2026-10-30.md` перенесены без изменений из
`documents/implementation/` в `documents/archive/`. Они не создают страниц
и пунктов меню. Ссылки на архивные Markdown-источники в публикуемых планах
обрабатываются существующим механизмом непубликуемых источников; сами тексты
планов не переписывались. Сохранённые облачные записи не менялись.

## Проверки

- `npm run test:editor`: 16 проверок прошли, включая состав каталога, ссылки
  на обоих базовых адресах и контрольные суммы исходных требований/D01–D13.
- `npm run typecheck`: пройдено.
- `npm run verify:evidence`: пройдено, 475 ссылок/связей и 130 фрагментов.
- `npm run build`: пройдено для корня и `/C4_metall/`, по 11 страниц.
  Осталось существующее предупреждение о размере JavaScript-пакетов.
- В Chrome на корневой локальной сборке проверены сворачивание категории
  кликом, раскрытие Enter/Space, переход к инженерным расчётам, выделение
  выбранного документа, раскрытие мобильной навигации и её закрытие после
  перехода по оглавлению. В категории ровно две ссылки.

## Границы

Скриншоты Chrome через CDP завершились таймаутом. Попытка получить снимок
через нативное окно была остановлена инструментом из-за невозможности
надёжно определить текущий URL. Поэтому визуальный снимок не получен;
взаимодействия подтверждены состоянием страницы и деревом доступности.
После пересборки с другим base уже запущенный корневой preview-сервер
не обслуживал `/C4_metall/`: браузерная проверка этого адреса не заявляется.

Архитектурный снимок и исходный продукт `metall-dev-2` не обновлялись.
