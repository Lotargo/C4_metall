Лендинг для инвесторов и заказчиков: понятный рассказ о процессе, реальные
скриншоты интерфейса и раскрываемые технические детали. Astro 7, статическая
сборка, локальные шрифты IBM Plex Sans, TypeScript и интерактивная схема C4.
Результат задачи находится только в `F:\projects\C4_metall`.

`/` — презентация для руководства и инвесторов без ссылок на код и IT-обозначений.
`/it/` — технический разбор, открываемый в новой вкладке ссылкой «Для IT».
Он содержит исходники, C4, контракты и схемы хранения.

## Работа

```powershell
npm ci
npm run dev
npm run verify:evidence
npm run typecheck
npm run build
```

Разработка: порт 4325. Просмотр статической сборки: `npm run preview`, порт 4326.
Сборка находится в `dist/`.
Проверка ссылок и схем работает из чистого клона; проверка исходных байтов
дополнительно выполняется, если доступен локальный `.evidence/source/`.

Для сознательного обновления снимка и атласа:

```powershell
node scripts/capture-source.mjs
node scripts/build-evidence.mjs
```

После нового снимка необходимо вручную сверить пояснения и диаграммы с кодом:
генератор не выводит архитектуру автоматически и не подтверждает смысл утверждений.
Не обновляйте снимок автоматически во время чужих работ.

## Публикация

Sites project ID сохранён в `.openai/hosting.json`; статическая директория — `dist`.
Токены публикации не сохраняются в репозитории. Исходники и пакет публикуются
штатным Sites source helper, затем сохраняется версия и развёртывается лендинг.

Перенос на другое статическое размещение требует только загрузки `dist/`.
Для GitHub Pages на пути репозитория нужно настроить `base` в Astro и префикс
публичных ссылок; для корня домена изменений не требуется.

## Интерактивность

- Семь глав режима показа; кнопки и клавиатура, прокручиваемые главы, выход Escape.
- Восемь этапов с понятным рассказом и отдельными параметрами реализации.
- Разбор распознавания в четырёх действиях и подробное описание режимов и ограничений.
- Три датированных скриншота интерфейса, переключение и просмотр в исходном размере.
- Девять раскрываемых ролей с условиями, входом, выходом и типом исполнения.
- Смысл пяти колонок геометрии, формы записи, места хранения и пояснения SQL-строк.
- C1/C2/C3/C4 на отдельной странице для IT, четыре фокуса, связи и входы/выходы.
- Масштаб, перемещение, полный экран, SVG-экспорт и ссылка на выбранный блок.
- SQL-схемы шести групп данных, вложенная структура паспорта и виды строк таблицы.
- Поиск оснований, просмотр исходника с номерами строк и SHA-256, JSON-экспорт.
- Навигация клавиатурой, семантические вкладки, модальный просмотр кода и печать.
