# Подготовка производства

Локальный Astro-лендинг с обзором продукта, результатами чтения чертежей и отдельной статьёй о создании 3D-модели. Актуализация от 13 ноября 2026 года. Маршрут и смета отмечены как развивающиеся части продукта.

## Запуск и проверка

Нужны Node.js 24.12+ и npm.

```sh
npm ci
npm run dev
```

Локальный просмотр — `http://127.0.0.1:4325/`.

```sh
npm run typecheck
npm run test:editor
npm run verify:evidence
npm run build
```

`build` автоматически запускает проверку публичного содержимого, ссылок и ассетов. Отдельно: `npm run verify:public`. Для проверки префикса сайта задайте `BASE_PATH=/C4_metall/` перед сборкой; проверка использует тот же префикс. `npm run preview` показывает статическую сборку на порту 4326.

`verify:evidence` проверяет локальные исторические свидетельства, включая приватный архив. Он не доказывает актуальность старого описания и не подменяет проверку текущих публичных текстов. Архив не нужен для обычной сборки сайта.

## Изменение содержимого

Инструкция с примерами — [docs/CONTENT_EDITING.md](docs/CONTENT_EDITING.md).

| Содержимое | Где редактировать |
| --- | --- |
| Основной рассказ, карточки и роли | `content/public/overview/` — один Markdown-файл на раздел |
| Результат отдельного чертежа | `content/public/results/` — один JSON на деталь |
| Свежие длинные скриншоты | `public/results/current/` |
| Текст отдельной 3D-статьи | `content/public/models/article.md` |
| Названия, параметры и ограничения 3D-примеров | `content/public/models/examples.json` |
| Геометрия для показа | `public/models/` — только очищенные данные отображения |
| Читательские планы и документация | `content/public/plans/`, `content/public/documentation/` |
| Входящие данные и историческое сравнение | `content/public/articles/` |

Меню главной и карточки результатов собираются из содержимого автоматически. Чтобы обновить маршрут или смету, достаточно изменить соответствующий раздел и его дату, затем проверить сборку. Читательские планы отделены от канонических исходных документов, которые сохраняются локально без правок.

## Интерфейс

Общие шапка, навигация, футер, Inter Variable и Lucide-иконки образуют единую визуальную систему. У главной собственный анимированный баннер с остановкой, автоматической паузой вне экрана и поддержкой уменьшенного движения.

Схема поддерживает выбор участников, шагов и связей. Роли можно искать и раскрывать. Длинные скриншоты открываются с прокруткой и переключением масштаба.

3D-просмотрщик показывает два подготовленных примера: вращение, масштаб, ракурсы, сечение, контуры, сетка и выбор граней. Отрисовка выполняется по изменениям; постоянного цикла вращения нет. Построение новых моделей на сайте не запускается. Загрузка примеров не требует подключения к рабочему продукту.

## Приватность и публикация

Раздела для IT, скачиваемого описания внутренней архитектуры и текстов внутренних инструкций в публичной сборке нет. Старые скриншоты, исходные выгрузки и вложения сохранены в локальном архиве `outputs/content-refresh-2026-11-13/retired/` и не должны возвращаться в `public/` автоматически.

В публичные файлы нельзя добавлять служебные пути, имена исходных файлов продукта, коммиты, ссылки на исходники, инструкции агентов, рабочие базы, журналы и секреты. Проверка сборки дополняет ручной просмотр текста и изображений.

`.evidence/`, `.local/`, `outputs/`, `dist/` исключены из Git. В них хранятся локальные свидетельства и материалы проверки. Рабочий продукт использовался только для чтения.

**Публикация и push запрещены без отдельного прямого поручения пользователя.** Push может запускать автоматическое развёртывание. Наличие скриптов публикации не даёт разрешения на их запуск.
